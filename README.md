## 🚀 Featured Project

### AIVORA — Local AI Desktop Automation Agent

*A secure, multilingual, locally hosted agentic system for natural-language-driven desktop automation.*

Developed as my final-year engineering project at TALAN Tunisie, AIVORA transforms natural-language instructions into desktop actions while keeping processing and user data on the local machine.

**Key engineering contributions:**

- 🧠 **Agentic pipeline:** Intent classification, planning, execution, and validation.
- 🤖 **Local LLM integration:** Role-specific models orchestrated through Ollama.
- 👁️ **Desktop perception:** Combines accessibility trees, UI automation, and vision models.
- 🗂️ **Retrieval-augmented memory:** Uses ChromaDB and task history to retrieve relevant context.
- 🛡️ **Security by design:** Risk-aware execution, human approval for sensitive actions, and execution safeguards.
- 🌐 **Multilingual interaction:** Supports English, French, and Arabic, with voice and text interfaces.

**Built with:** Python · FastAPI · Next.js · Electron · Ollama · ChromaDB · SQLite · Playwright

The goal: make desktop automation more accessible without sacrificing privacy, transparency, or user control.
